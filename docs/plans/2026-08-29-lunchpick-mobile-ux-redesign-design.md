# LunchPick UX/UI 개선 설계 (2026-08-29)

## 배경

지난 디자인 점검 세션에서 줄간격, 폰트, 이미지 로딩 버그, 터치 영역 등을 고쳤다. 이번 세션은 그 다음 라운드로, 사용자가 세 가지를 요청했다:

1. 혼밥 추천 화면의 랜덤 스톡사진(picsum.photos)을 없애고 기능 중심으로 정리
2. 모바일에서 헤더의 "혼밥 추천"/"팀 투표" 탭 글자가 두 줄로 꺾이는 문제
3. 전체 앱을 UX/UI 관점에서 점검

대상 파일은 전부 `src/App.tsx` 하나 (컴포넌트 분리 없이 단일 파일 구조).

## A. 혼밥 추천 히어로 — 사진 제거, 1단 레이아웃

**현재**: `grid lg:grid-cols-2` 2단 구조. 왼쪽에 배지+제목+추천카드+새로고침 버튼, 오른쪽에 `picsum.photos` 랜덤 이미지 (App.tsx:158-202).

**변경**:
- `grid lg:grid-cols-2` → 1단 (`div` 그대로, grid 제거하고 `max-w-2xl` 정도로 폭 제한 + 내부 요소는 기존 `space-y-8`/`space-y-4` 유지)
- 오른쪽 `<img>` + 그라디언트 오버레이 블록(App.tsx:194-202) 전체 삭제
- 추천 식당 카드(`p-8 bg-[#f9f9f9] rounded-3xl`, App.tsx:171-182)는 시각적 비중을 키우기 위해 패딩/폰트 크기를 한 단계 키움 (`p-8` → `p-10`, 식당명 `text-3xl` → `text-4xl`)
- 새 장식 요소는 추가하지 않음 — "사진 자리를 채우는" 접근이 아니라 "정보를 크고 명확하게" 접근

## B. 모바일 헤더 — 2줄 레이아웃, 큰 탭 2개

**현재**: `header` 안에 `flex items-center justify-between` 한 줄로 로고 + `nav`(pill 탭 2개, `px-6 py-2`)가 나란히 배치. 좁은 화면에서 탭 버튼 폭이 부족해 글자가 줄바꿈됨 (App.tsx:120-144).

**변경**:
- 헤더 컨테이너를 `flex-col sm:flex-row`로 바꿔 모바일에서는 로고 줄 / 탭 줄이 세로로 쌓이게 함
- 탭 `nav`에 모바일 전용 `w-full` + 내부 버튼 `flex-1`을 줘서 폭 절반씩 차지하는 큰 버튼으로 (`sm:` 이상에서는 기존 pill 스타일로 복귀, `sm:w-auto` `sm:flex-none`)
- 헤더 높이(`h-20`)는 모바일에서 2줄이 되므로 고정 높이를 풀고 `py-3` 등으로 자연스러운 높이로 전환. `sticky top-0`은 유지하되 2줄이 되어도 어색하지 않은지 스크린샷으로 재확인

## C. 모바일 팀투표 — 콘텐츠 순서 변경

**현재**: `grid lg:grid-cols-[350px_1fr]` 구조에서 `<aside>`(투표 관리 안내 + 접속자 카드)가 JSX상 먼저, 실제 투표 후보 카드 영역이 나중에 옴 (App.tsx:215-296 부근). 데스크톱은 그리드라 사이드바로 빠지지만, 모바일은 세로로 그대로 쌓여 안내 카드 2개를 지나야 투표 카드가 나옴.

**변경**:
- `<aside>`에 `order-2 lg:order-none`, 투표 후보 영역 컨테이너에 `order-1 lg:order-none` 부여 (CSS order 속성으로 모바일에서만 순서 역전, 데스크톱 그리드 레이아웃은 영향 없음)
- DOM 순서/접근성 트리는 그대로 두고 시각적 순서만 CSS로 바꾸는 방식이라 리스크 낮음

## 범위 밖 (이번엔 안 함)

- 실제 음식 사진 넣기 — 사용자가 "사진은 필요 없을 것 같다"고 확정
- 회색 보조텍스트(#9e9e9e) 대비 조정 — 우선순위 낮음으로 보류, 필요시 추후 별도 요청

## 검증 방법

로컬 dev 서버(localhost:3000)에서 gstack browse로 데스크톱(1280px)·모바일(390px) 스크린샷 비교. 특히:
- 혼밥 추천 화면 1단 레이아웃이 데스크톱에서 허전해 보이지 않는지
- 헤더 2줄 전환이 `sm` 브레이크포인트 부근에서 어색하지 않은지
- 팀투표 모바일에서 투표 카드가 스크롤 없이/최소 스크롤로 보이는지
